Gmail Notification

A browser extension that helps you quickly see unread Gmail messages and preview incoming emails without leaving your current tab.

About Gmail Notification

Gmail Notification is a browser extension designed to make Gmail notifications easier to see and manage. It displays the number of unread Gmail messages and provides a quick popup preview of email information.

The extension is designed to reduce the need to repeatedly open Gmail just to check whether new messages have arrived.

Features

  • Displays the number of unread Gmail messages.
  • Provides a quick popup preview of email information.
  • Supports multiple Gmail accounts.
  • Provides notification and sound-alert features when enabled.
  • Provides a floating notification button when enabled.
  • Works with Gmail through Google OAuth authorization and the Gmail API.

How Gmail Authorization Works

Gmail Notification uses Google's OAuth authorization system to connect the extension to the Gmail account selected by the user.

Authorization is performed through Google's own sign-in and consent pages. Users can revoke the extension's access to their Google Account through their Google Account settings.

Gmail Notification is an independent browser extension and is not affiliated with, sponsored by, or endorsed by Google LLC.

Privacy

The extension uses Gmail API access to provide its Gmail notification and email-preview functionality. Please review the Privacy Policy for information about data handling and permissions.
